# 15. 3Sum (LeetCode)

**Difficulty:** Medium
**Topic:** Two Pointers
**Constraint:** Must run in $\mathcal{O}(n^2)$ time and the solution set must not contain duplicate triplets.

---

## 📝 Problem Description

Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.

*   **Crucial Constraint:** The solution set must **not** contain duplicate triplets.

### Examples

**Example 1:**
* **Input:** `nums = [-1,0,1,2,-1,-4]`
* **Output:** `[[-1,-1,2],[-1,0,1]]`
* **Explanation:** 
  `nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0`.
  `nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0` (equivalent triplet, ignored).
  `nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0`.
  The distinct triplets are `[-1, 0, 1]` and `[-1, -1, 2]`.

**Example 2:**
* **Input:** `nums = [0,1,1]`
* **Output:** `[]`
* **Explanation:** The only possible triplet sums up to 2 (not 0).

**Example 3:**
* **Input:** `nums = [0,0,0]`
* **Output:** `[[0,0,0]]`
* **Explanation:** The only possible triplet sums up to 0.

### Constraints
* `3 <= nums.length <= 3000`
* `-10^5 <= nums[i] <= 10^5`

---

## 🧠 The Mental Model: Sorting + Two Sum II
A brute-force 3-loop approach takes $\mathcal{O}(n^3)$ time, which is far too slow. 

By **sorting the array first**, we unlock a brilliant $\mathcal{O}(n^2)$ architecture:
1. We lock in a starting number using a standard `for` loop (`nums[i]`).
2. The problem instantly transforms into **Two Sum II**: we use `start` and `end` pointers on the *remaining* part of the array to find two numbers that sum up to `-nums[i]`.
3. **Handling Duplicates:** To ensure no duplicate triplets are added to our result, we apply two layers of safety checks:
   * **Outer Loop:** If `nums[i]` is identical to the previous number (`nums[i - 1]`), we skip it entirely using `continue`.
   * **Inner Pointers:** The moment we find a valid triplet and move `start` and `end` inward, we use fast-forward `while` loops to skip over any identical adjacent numbers.

---

## 💻 Optimal Java Solution ($\mathcal{O}(n^2)$ Time)

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {

        List<List<Integer>> finalList = new ArrayList<>();

        //[-1,0,1,2, -1,  -4 ] 
        //           n-2, n-1, n

        int n = nums.length;

        // sorted
        Arrays.sort(nums);

        // n-2 for triplet
        for(int i=0; i<n-2; i++){

            // sProcess the First, Skip the Later
            if (i > 0 && nums[i] == nums[i - 1]) continue;
                
            int start = i+1; // start will be next to (i)
            int end = n-1;

            while(start < end){

                if(nums[i] + nums[start] + nums[end] == 0){
                    // found triplet
                    finalList.add(List.of(nums[i], nums[start], nums[end]));
                    start++;
                    end--;

                    // skip duplicates
                    while (start < end && nums[start] == nums[start - 1]) start++;
                    while(start < end && nums[end]==nums[end+1]) end--;
                    

                }else if(nums[i] + nums[start] + nums[end] < 0){
                    start++;
                }else{
                    end--;
                }

            }
            

        }

        return finalList;


    }
}
